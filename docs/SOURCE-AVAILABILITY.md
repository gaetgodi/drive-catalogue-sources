Large corresponding-source archives are planned as version-specific GitHub Release assets. Do not commit these archives to Git.

For each future application version, record:

- Exact application version and associated release tag.
- Component names, exact versions, upstream source URLs, and local modifications.
- Source archive filenames, byte sizes, SHA-256 checksums, and release asset links.
- Applicable license and notice files.
- Matching build documentation and any required build scripts or patches.
